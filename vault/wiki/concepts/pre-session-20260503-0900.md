## Before You Sit Down

- **3BP M2 — No fast play.** Set/overpair on a safe turn: if checking lets Kx/Ax bet into you → check. Betting folds all bluffs = wrong.
- **3BP M3 — Block or check-call, not check.** Mid-strength + blank turn: block bet 33–50% if you block their bluffs; check-call if you unblock them.
- **SRP M1 — CR for protection.** BB defend, IP over-cbets: ask 3 questions — (a) IP over-cbets? (b) Protection needed? (c) bdfd/gutshot? All yes → check-raise, never check-call.
- **3BP M1 — Big bet on drawy boards.** Strong top pair+ on flush-draw board → bet 87%+ pot. Never size down here.
- **SRP M3 — bdfd = bluff combo, not bluff-catch.** bdfd + overcard + pool over-cbets → check-raise bluff. Never check-call this.
