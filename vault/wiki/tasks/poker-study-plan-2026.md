## Study Rhythm (What to Do Each Window)

### TUE 17:30–19:30 (2h) — Deep Work
- Watch Tony clip for current spot (45–60 min)
- Write raw notes → drop in `raw/`
- Review key concepts, note questions

### THU 17:30 (15 min) — Quick Recall
- Run `/recall` for 10–15 questions
- Log result

### FRI 17:30–19:00 (1.5h) — Ingest + Vault
- Run `/ingest` on raw notes from TUE
- Review inbox draft, tag correctly
- Run `/approve` when ready

### SAT 10:45–12:00 (1h15m) — Hand Review
- Review 3–5 key hands from TUE/THU/FRI sessions
- Tag notable hands for `/hand-review`
- Update `wiki/hands/` with reviewed hands

### SAT 15:00–16:00 (1h) — Prep + Admin
- Run `/session-prep` for evening session
- `/approve` any pending inbox drafts
- Update master-todo checkboxes

### SUN 10:30–12:00 (1.5h) — Week Review
- Review all sessions from the week
- Update hand count tracker
- Plan next week: confirm current spot, check recall due dates
- Log week summary in weekly note
