# 3BP OOP PFR — Study Task List & Progress Tracker

Task list to fix the [[spots/3bp-oop-pfr-flop-key-mistakes|5 key mistake patterns]] from Tony's 20-hand coaching session. Work through each module in order — earlier modules are prerequisites for later ones.

---

## Module 1 — Board Reading: Identify Drawy vs Safe Boards

**Goal:** Before deciding bet size, correctly classify the board as drawy (flush draw / connected) or safe (rainbow / paired / low-connectivity).

- [ ] **Task 1.1** — Drill 20 flop textures. For each, label: drawy / safe / borderline. Check against solver or Tony's framework.
- [ ] **Task 1.2** — Write a one-line decision rule: "If board is drawy + I hold strong top pair or better → bet big (87%+)."
- [ ] **Task 1.3** — In next 3 sessions, tag every hand where you chose a bet size on a drawy board. Review after the session.

**Done when:** Zero occurrences of small-bet-strong-value on drawy boards for two sessions in a row.

---

## Module 2 — Protection Need Check (Fast Play vs Check)

**Goal:** Before betting value on the turn, ask: "Does this hand need protection? Will IP bet anyway if I check?"

- [ ] **Task 2.1** — Study the 6 hands from Mistake 2 (hands 4, 5, 7, 8, 10, 12). For each, write one sentence on why checking was better.
- [ ] **Task 2.2** — Build a mental checklist: (a) Do I have a set or overpair? (b) Will Kx or Ax bet if I check? (c) Does betting fold out all bluffs? If all yes → check.
- [ ] **Task 2.3** — Spot drill: given 5 spots with sets/overpairs, decide bet vs check using checklist. Verify with solver.
- [ ] **Task 2.4** — In next session, mark every turn decision with set or overpair. Review after.

**Done when:** Consistently checking set/overpair in no-protection spots across 2 sessions.

---

## Module 3 — Block Bet to Prevent 0 EV Scenario

**Goal:** Recognize when opponent's range is full of 0-equity hands, and use small block bet (33–50%) to extract value.

- [ ] **Task 3.1** — Study the 5 hands from Mistake 3 (hands 14, 16, 18, 19, 20). Identify what the opponent's 0-equity region is in each.
- [ ] **Task 3.2** — Learn to distinguish: "Should I check-call or block?" Use the cue: if my hand unblocks their bluffs → check-call. If my hand blocks their bluffs → block bet.
- [ ] **Task 3.3** — Drill 5 spots with medium-strength hands on blank turns. Decide: block or check-call. Compare with solver.
- [ ] **Task 3.4** — In next session, identify at least 1 spot to use block bet that you would have previously checked.

**Done when:** Comfortable distinguishing check-call vs block in 0 EV prevention spots.

---

## Module 4 — Big Draw Equity Realization Line

**Goal:** When holding a big draw (combo draw, gutshot + flush draw), plan the full equity realization line before acting.

- [ ] **Task 4.1** — Review hand 11 (J9 on QT7). Map out all 3 lines: (a) bet-call jam, (b) bet-fold, (c) check-raise all-in. Calculate EV roughly.
- [ ] **Task 4.2** — Decision tree: "Can I bet-call a jam?" If yes → bet. If no → check-raise all-in.
- [ ] **Task 4.3** — Drill 3 big-draw spots. For each, determine which line to take before looking at solver output.

**Done when:** Automatically thinking "can I bet-call a jam?" before betting big draws.

---

## Module 5 — C-Bet Turn with Equity Hand

**Goal:** On favorable turns where the range picks up equity, c-bet with gutshots and equity draws to pressure the pocket pair region.

- [ ] **Task 5.1** — Review hand 15 (J9 on A73-T). Understand why the turn T makes J9 a good c-bet: (a) picks up equity, (b) opponent's pocket region has no improvement, (c) 50% pot attacks their fold threshold.
- [ ] **Task 5.2** — Write the rule: "Favorable turn + gutshot/equity hand + opponent pocket region weak → c-bet 50%."
- [ ] **Task 5.3** — Drill 5 turn spots with equity hands. Decide c-bet or check. Verify with solver.

**Done when:** Not missing profitable turn c-bets with equity hands over 2 sessions.

## Session Review Protocol

After each live session:

- [ ] Tag every hand involving a 3BP OOP spot.
- [ ] For each tagged hand, note which mistake category applies (1–5).
- [ ] Add the hand to the relevant study module above.
- [ ] At end of week, count mistakes per category. The category with the most mistakes → priority for next study session.
